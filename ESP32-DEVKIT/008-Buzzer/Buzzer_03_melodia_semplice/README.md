# Buzzer 03 melodia semplice

Scala ripetuta e pause tra le note.

## Preparazione

GPIO buzzer 27. Per il piezo passivo usa 1 kΩ in serie; per il buzzer attivo della 01 usa un modulo o stadio di comando adeguato, secondo la guida. Consulta la [guida della raccolta](../README.md) per teoria, circuito specifico e dipendenze.

Apri [Buzzer_03_melodia_semplice.ino](Buzzer_03_melodia_semplice.ino) in Arduino IDE dalla cartella attuale. Seleziona scheda ESP32 e porta corrette; carica un solo sketch alla volta. Per i messaggi usa il monitor seriale a 115200 baud, quando previsto. Mantieni nella cartella anche gli eventuali file `.h` e `.cpp`.

È incluso [diagram.json](diagram.json): copialo insieme al programma nel progetto Wokwi corrispondente, seguendo la guida della raccolta.

## Prova ed esercizio

Cambia una frequenza o durata e prevedi il risultato; verifica anche la condizione di silenzio.

Registra versione del core o firmware, collegamenti e risultato osservato; lo schema simulato non verifica alimentazione e correnti reali.
