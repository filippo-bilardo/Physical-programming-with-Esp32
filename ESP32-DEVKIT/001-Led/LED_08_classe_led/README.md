# LED 08 classe led

La classe locale gestisce il LED 18 con 220 Ω: acceso, spento, inversione, lampeggio e luminosità PWM. begin() inizializza l’hardware in setup().

## Preparazione

Consulta la [guida della raccolta](../README.md) per teoria, circuito specifico e dipendenze.

Apri [LED_08_classe_led.ino](LED_08_classe_led.ino) in Arduino IDE dalla cartella attuale. Seleziona scheda ESP32 e porta corrette; carica un solo sketch alla volta. Per i messaggi usa il monitor seriale a 115200 baud, quando previsto. Mantieni nella cartella anche gli eventuali file `.h` e `.cpp`.

È incluso [diagram.json](diagram.json): copialo insieme al programma nel progetto Wokwi corrispondente, seguendo la guida della raccolta.

## Prova ed esercizio

Crea un secondo oggetto e rendi i lampeggi indipendenti senza attese lunghe.

Registra versione del core o firmware, collegamenti e risultato osservato; lo schema simulato non verifica alimentazione e correnti reali.
