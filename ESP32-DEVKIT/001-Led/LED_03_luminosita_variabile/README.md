# LED 03 luminosita variabile

LED 18 con 220 Ω; PWM a 8 bit, 5 kHz, rampa 0–255 e ritorno, con passo temporale 10 ms.

## Preparazione

Consulta la [guida della raccolta](../README.md) per teoria, circuito specifico e dipendenze.

Apri [LED_03_luminosita_variabile.ino](LED_03_luminosita_variabile.ino) in Arduino IDE dalla cartella attuale. Seleziona scheda ESP32 e porta corrette; carica un solo sketch alla volta. Per i messaggi usa il monitor seriale a 115200 baud, quando previsto. Mantieni nella cartella anche gli eventuali file `.h` e `.cpp`.

È incluso [diagram.json](diagram.json): copialo insieme al programma nel progetto Wokwi corrispondente, seguendo la guida della raccolta.

## Prova ed esercizio

Sostituisci le attese con millis() e aggiungi un pulsante.

Registra versione del core o firmware, collegamenti e risultato osservato; lo schema simulato non verifica alimentazione e correnti reali.
