# LED 06 led rgb

LED RGB a catodo comune a GND, R/G/B rispettivamente 18/19/21 con una resistenza da 220 Ω per colore. Mostra i colori base e transizioni PWM.

## Preparazione

Consulta la [guida della raccolta](../README.md) per teoria, circuito specifico e dipendenze.

Apri [LED_06_led_rgb.ino](LED_06_led_rgb.ino) in Arduino IDE dalla cartella attuale. Seleziona scheda ESP32 e porta corrette; carica un solo sketch alla volta. Per i messaggi usa il monitor seriale a 115200 baud, quando previsto. Mantieni nella cartella anche gli eventuali file `.h` e `.cpp`.

È incluso [diagram.json](diagram.json): copialo insieme al programma nel progetto Wokwi corrispondente, seguendo la guida della raccolta.

## Prova ed esercizio

Aggiungi un colore con tre duty diversi e confronta il risultato.

Registra versione del core o firmware, collegamenti e risultato osservato; lo schema simulato non verifica alimentazione e correnti reali.
